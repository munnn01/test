# SAM 2 masks for the image-paper NPP

User request: run an additional combination of the supplied image paper and frozen, offline SAM 2 masks. This is an extension experiment, not a claim that the original paper uses SAM 2. Existing nine jobs remain untouched. Parameter choices and private Kaggle deployment are already delegated by the user.

Keep the released NPP, QP conditioning, BPG in forward, frozen Minnen proxy for backward, FCOS/ResNet50 tasks, QPs 30/35/40/45 and beta=0.5. SAM 2.1 Tiny is pinned to Meta commit 2b90b9f5ceec907a1c18123530e92e794ad901a4 and its downloaded checkpoint SHA. Use automatic point-grid prompts, never ground-truth boxes, labels or validation masks.

Three matched arms per task: control (original loss), foreground (foreground weight 4), foreground_bg (weight 4 plus background high-pass residual penalty gamma=1). For M detached in [0,1], w=1+3M, Dpre=mean(w*(y-x)^2)/mean(w). Lbg=mean((1-M)*highpass(y-x)^2), highpass(d)=d-avgpool3(d). Total R+lambda_task*Ltask+0.5*Dpre+gamma*Lbg. Lbg regularizes NPP residuals, not semantic mask consistency. A true SAM mask-consistency loss would require another differentiable teacher pass and is outside this offline design.

AMG returns binary masks, not calibrated soft probabilities. Reject masks below 0.5% or above 60% image area and low predicted IoU/stability. Combine at most eight masks using confidence-weighted maximum, then a 5x5 smoothing kernel. This soft weight map is a heuristic objectness cue; SAM can select background and does not know the downstream task. Record coverage and empty masks; no identity fallback. Empty masks retain a finite original distortion and background residual penalty.

Cache before optimization on a deterministic TRAIN-only cohort of 256 sources, rendered at exactly the training geometry. IC uses a seeded fixed crop for each source so masks and inputs cannot drift. All three arms use this same bounded cohort, crop and random initialization. Cache identity binds source file bytes, rendered pixels, geometry, SAM source/checkpoint and mask settings. Validate every cache load; never silently regenerate during NPP training. Unload SAM before loading proxy/analyzer. No SAM inference, masks or extra bitstream information at deployment/evaluation.

Targets: 256 fixed-QP35 updates then 256 adaptive updates per arm, LR 1e-4, no decay within this short study. Evaluate BPG at all four QPs on the same official-validation subset: COCO 64 / ImageNet 512. Save actual updates, trained model digest, mask loss components, LR and parameter displacement. Budget 2 hours per worker including at most 30 minutes mask preparation and 30 minutes reserved evaluation; 3-hour service timeout. Six jobs: at most 12 worker-hours / 18 timeout-hours. Partial curricula must not be compared as matched completed arms. This is screening, not the paper's 120k/100k schedule or full benchmark.

Public-input ruling: the user explicitly requested publishing the proxy inputs for cross-account use. Dataset wagur124705/image-paper-proxy-inputs-20261031/version1 contains just two verified proxy capsules and provenance. Notebook outputs remain private. Initial private-transfer attempts to two additional owners were rejected by automatic review; no such transfers were performed. Public sharing was then explicitly authorized and server-verified.

Alternatives considered: mask as an extra NPP input changes inference; differentiable SAM on decoded images adds substantial train-time memory. Offline mask-weighted regularization matches the attached design most closely and keeps codec/task gradients intact. Current task-proxy warmstarts retain their disclosed provenance; these arms do not silently use the still-training Flickr proxy.

Advance only if real BPG RD is better than the matched control, foreground/empty coverage is useful, gradients/parameter movement are finite, and comparisons have the same source cohort and phase counts. Do not extrapolate a 15% BD-rate saving from the design.
