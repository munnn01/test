# Instance Segmentation, Detection and Tracking with offline SAM 2

The latest user explicitly requests all three proposed tasks: instance segmentation and object detection on COCO2017, object tracking on GOT10k. Keep the released image-paper NPP, QP conditioning, real codec forward, frozen learned proxy backward and frozen offline SAM 2 masks. No identity bypass or checkpoint fallback. Existing jobs stay unchanged.

Image segmentation: frozen Torchvision Mask R-CNN ResNet50 FPN COCO V1, official COCO2017 TRAIN/VAL, real BPG. Train with supervised detection/mask losses; evaluate unprompted COCO segmentation AP, without supplying GT boxes/masks to prediction. Object detection uses frozen FCOS ResNet50 FPN COCO V1 and bbox AP on the same COCO cohort. Tracking: frozen official DiMP50, GOT-10k TRAIN/VAL, real low-delay H.264, first box only at inference. Report AO/SR50/SR75 excluding the initialized frame and invisible frames. Clip/subset results are not full benchmark results.

SAM 2.1 Tiny uses pinned official code/checkpoint from the preceding study, generates automatic per-frame objectness maps on fixed TRAIN-only crops/clips, then unloads. No GT prompts for SAM. The downstream tracking head, rather than the offline mask teacher, maintains object identity. At deployment only NPP, codec and task model are required.

Matched control/foreground arms for each task. Same source pool, seed, proxy input, warm-up schedule and evaluation cohort. Foreground map M weights Dpre: w=1+3M, Dpre=mean(w*(y-x)^2)/mean(w). The masked arm also uses L_mask=mean((1-M)*highpass(y-x)^2), highpass(d)=d-avgpool3(d), with gamma0.1. Control uses M=0 and gamma0. Task objective Rreal +0.1*lambda_paper(QP)*Ltask +5*Dpre +gamma*L_mask. Forward reconstruction/rate come from the real codec; gradients come from the proxy. These coefficients are declared stability experiments, not the original beta/lambda schedule.

Latest priority: deploy only the four COCO segmentation/detection jobs first. Tracking stays in a separate later batch, with its own GOT10k data, calibration and runtime preflight. Do not imply its GPU path has been validated by COCO runs.

Never use BPG rate as H.264 rate.
